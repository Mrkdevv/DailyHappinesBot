# DailyHappinessBot

An asynchronous Telegram bot designed for daily mood tracking and maintaining a micro-journal.

## Features
* Customizable daily notification time for each user.
* Inline buttons for quick rating of the day on a scale from 1 to 10.
* Optional text comments to log thoughts and events for the day.
* Automatic statistical reports generated for the week, month, and year.

## Tech Stack
* Python 3.11+
* aiogram 3.x (Telegram Bot API framework)
* SQLite (Database for storing user profiles and logs)
* APScheduler (Asynchronous task scheduler for notifications)
